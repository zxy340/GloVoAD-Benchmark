# Matching Speech Models to ADRD Subtypes: An Exploratory Benchmark

Code and results for the article "Matching Speech Models to ADRD Subtypes: An Exploratory Benchmark" by Xiaoyu Zhang, Longxiang Pan, Wei Bo, Anarghya Das and Wenyao Xu, *Information* (MDPI), 2026.

The results reported in the article were produced with the code in [`article/`](article/). Its [README](article/README.md) lists the scripts, explains how to run them and describes the result files. These include the summary results and the out-of-fold predictions for every recording, identified by file name and without diagnostic labels.

The speech recordings come from DementiaBank and cannot be redistributed. DementiaBank membership can be requested at talkbank@cmu.edu.

## Earlier code

The folders `data_preparation/`, `feature_extraction/`, `benchmark/`, `region_masking/`, `linguistic_perturbation/` and `figures/` hold the code of an earlier version of this work, presented at ICIBM 2026. It covers seven models and does not reproduce the results of the article. Its original description is kept in [README_conference_version.md](README_conference_version.md).
